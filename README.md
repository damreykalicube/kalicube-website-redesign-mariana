## Edit it

1. Open the file on GitHub, click the pencil icon, make the change and click **Commit changes**.
2. The page updates within a minute or two.

Each page's folder holds the same page four times, once per Font Flip font:

Edit `index-ubuntu.html` first. Make the same change in the other three if you want the other fonts in Font Flip to match.
